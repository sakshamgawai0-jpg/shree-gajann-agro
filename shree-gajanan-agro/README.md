# श्री गजानन अॅग्रो (Shree Gajanan Agro - Khamgaon)

Official web application and live farmer catalog for **Shree Gajanan Agro**, Khamgaon (Dist. Buldhana, Maharashtra). Owned and operated by D. Bharambe.

## Features
- **Mobile-First Responsive Design**: Optimized for smartphones with a bottom quick-action navigation dock, fast touch interactions, and zero horizontal scroll.
- **Tri-lingual Language Support**: Real-time language switching between **मराठी (Marathi)**, **हिंदी (Hindi)**, and **English (EN)**.
- **Interactive Live Product Catalog**: Search, filter by category (*Seeds, Fertilizers, Pesticides, Drip Irrigation, Sprayers*), view live prices and stock statuses.
- **Direct WhatsApp Inquiries**: Instant 1-tap WhatsApp inquiries with pre-filled Marathi/Hindi/English order messages.
- **Persistent Admin Inventory Portal**:
  - Live inventory tracking (Total items, In stock, Limited stock, Out of stock).
  - Add, edit, toggle stock status, and delete products with browser `localStorage` persistence.
- **Store Location & Google Maps**: Embedded interactive map with one-tap directions to Cotton Market, Khamgaon.

## How to Run Locally
Open `index.html` directly in any web browser, or serve it using Python:
```bash
python -m http.server 5500
```
Then visit `http://localhost:5500`.
